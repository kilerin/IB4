# Быстрый старт

## Запуск одной кнопкой

### macOS / Linux
```bash
./run.sh
```

### Windows
```bash
run.bat
```

## Что дальше?

1. Откройте браузер и перейдите на http://localhost:5000
2. Перейдите в раздел **Wallets**
3. Добавьте свой первый кошелек, нажав **+ Add Wallet**
4. Используйте кнопку **Refresh** для обновления транзакций

## Основные функции

- **Добавление кошельков**: Нажмите "+ Add Wallet", введите имя и TRX адрес
- **Сортировка**: Перетаскивайте кошельки за иконку ☰ для изменения порядка
- **Скрытие кошельков**: Используйте иконку глаза для скрытия/показа кошельков
- **Обновление балансов**: Кнопка "Refresh Balances" обновит балансы всех кошельков
- **AML проверка**: Нажмите иконку 🔍 для проверки кошелька по AML
- **Фильтрация транзакций**: Используйте переключатели для скрытия малых сумм и TRX транзакций

## Примечания

- Приложение использует SQLite базу данных, которая создается автоматически
- Примеры данных добавляются при первом запуске
- Все данные хранятся локально в файле `crypto_deck.db`
