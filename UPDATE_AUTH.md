# Инструкция по обновлению с аутентификацией

## Шаги для обновления на сервере:

### 1. Подключитесь к серверу
```bash
ssh cryptoapp@178.130.42.24
```

### 2. Перейдите в директорию проекта
```bash
cd /home/cryptoapp/IB4DECK
```

### 3. Обновите код из Git
```bash
git pull origin main
```

### 4. Обновите файл .env
Добавьте переменные окружения для аутентификации:

```bash
nano .env
```

Добавьте или обновите следующие строки:
```env
SECRET_KEY=ваш-секретный-ключ-для-сессий
APP_PASSWORD=ваш-пароль-для-входа
TRONGRID_API_KEY=ваш-trongrid-api-key
BITOK_API_KEY_ID=ваш-bitok-api-key-id
BITOK_API_SECRET=ваш-bitok-api-secret
```

**Важно:**
- `SECRET_KEY` - случайная строка для шифрования сессий (можно сгенерировать: `python3 -c "import secrets; print(secrets.token_hex(32))"`)
- `APP_PASSWORD` - надежный пароль для входа в приложение
- `TRONGRID_API_KEY`, `BITOK_API_KEY_ID`, `BITOK_API_SECRET` обязательны для обновления балансов, транзакций и AML проверок

### 5. Пересоберите и перезапустите контейнеры
```bash
docker compose down
docker compose build --no-cache web
docker compose up -d
```

### 6. Проверьте статус
```bash
docker compose ps
docker compose logs web
```

### 7. Проверьте работу
Откройте браузер и перейдите на `http://178.130.42.24`
Вы должны увидеть страницу входа. Введите пароль, который указали в `APP_PASSWORD`.

## Быстрое обновление (если уже настроен deploy.sh)

Если у вас настроен автоматический деплой, можно использовать:
```bash
./deploy.sh
```

Но не забудьте обновить `.env` файл перед этим!

## Примечания

- После обновления все пользователи должны будут войти заново
- Пароль хранится в переменной окружения `APP_PASSWORD`
- Для безопасности рекомендуется использовать сложный пароль
- Кнопка "Выйти" находится в нижней части боковой панели
